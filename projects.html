01 / Research tools

Built during the Ph.D.

LLM-assisted proof · 2025

DAISY

The Dafny Assertion Inference System. When Dafny gives up on a proof, DAISY combines LLM predictions with the verifier's error messages to propose the helper assertions that are missing, including several at once. It comes with an extension of DafnyBench whose programs have had assertions removed.

Specification quality · 2026

ProofPulse

Interactive proof-coverage analysis. A three-valued model classifies each spec element as essential, auxiliary or irrelevant to the proof, which exposes vacuous proofs and unnecessary preconditions. Evaluated on 252 programs.

Testing · 2026

DSpec2Test

Generates tests from the specification alone, without looking at the implementation. It uses DNF equivalence-class partitioning and boundary-value analysis, with Z3 synthesizing inputs and expected outputs. The tests kill 93.9% of mutants.

Debugging · ISSRE 2026

Fault localization

Ranks the statements most likely to cause a failed verification using counterexamples from several traces. Evaluated with MutDafny mutants of DafnyBench programs.

Repair · FCT project

VeriFixer

An open-source tool that automatically fixes problems reported by software verifiers, starting with Dafny. It is a collaboration between INESC TEC, INESC-ID and Carnegie Mellon. DafnyFix, which repairs programs with a single transformation, is part of this work.

LLM plugin · FormaliSE 2024

Lemma suggester

A Dafny plugin that asks an LLM for lemmas Dafny cannot find on its own, and for a calculational proof when a lemma does not verify automatically.

Side project · Rust

TraceLean IDE

A code editor built on command sourcing, with an AI coding agent inside it. Every edit, whether you or the agent made it, is a small undoable command, so a session's history is a tree you can navigate instead of a linear undo stack. It runs as a Tauri + React desktop app, a Ratatui terminal UI, or headless CLI agents for benchmarks.

03 / Before the Ph.D.

Silicon & university

Synopsys · 2021–2024 · verification lead

MIPI CSI-2 camera controllers

I led verification for a new generation of CSI-2 camera controllers for automotive use. I built constrained-random UVM environments that model the design under test, wrote temporal assertions derived from the MIPI specifications, and used formal verification (VCFormal) on the parts of the design that needed stronger guarantees. I hold an ISO 26262 certification for automotive functional safety.
