  1. ISSREConference

    Improving Debugging in Verification-Aware Languages Through Automated Fault Localization: A Case Study in Dafny

    Álvaro Silva, Isabel Amaral, João Pascoal Faria, Alexandra Mendes

    A comparison of state-based and counterexample-based fault localization for failing Dafny verifications, evaluated on mutated DafnyBench programs. Counterexample-based localization, using structured ranking and aggregation over several traces, performs substantially better.

  2. arXivPreprint

    ProofPulse: Interactive Proof Coverage Analysis for Dafny

    Álvaro F. Silva, Ruben Martins, Alexandra Mendes

    A three-valued proof-coverage model that shows which specification elements a proof depends on and which are auxiliary or irrelevant. On 252 programs it detects unnecessary preconditions and vacuous proofs well, especially when combined with unsat-core minimization.

    arXiv PDF Code
  3. arXivPreprint

    DSpec2Test: Specification-Driven Test Generation in Dafny

    Sofia Vieira Pinto, Álvaro F. Silva, João Pascoal Faria, Alexandra Mendes

    Black-box test generation from Dafny specifications. It partitions the spec into equivalence classes in disjunctive normal form, optionally adds boundary-value analysis, and uses Z3 to synthesize inputs and expected outputs. The generated tests kill 93.9% of mutants, more than an implementation-based baseline.

    arXiv PDF Code

  1. arXivPreprint

    Inferring Multiple Helper Dafny Assertions with LLMs

    Álvaro Silva, Alexandra Mendes, Ruben Martins

    Introduces DAISY (Dafny Assertion Inference SYstem), which combines LLM predictions with analysis of verifier error messages, and extends DafnyBench with programs whose assertions have been removed. DAISY repairs 63.4% of programs missing one assertion and 31.7% of programs missing several.
